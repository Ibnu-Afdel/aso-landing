## Generate the model

```bash
aso make:model Todo -mcr --fields="title:string done:boolean user:foreign"
```

`-m` also creates a migration, `-c` a controller, and `-r` makes that controller a resource
controller (all seven `index`/`create`/`store`/`show`/`edit`/`update`/`destroy` methods).
`--fields` writes typed columns straight onto the model and the migration; `user:foreign` adds
a `user_id` foreign key to `users.id`.

This writes `app/models/todo.py`:

<CodeFile name="app/models/todo.py">
```python
from sqlalchemy import Boolean, ForeignKey, String
from aso.database import Mapped, Model, belongs_to, mapped_column
from typing import TYPE_CHECKING
if TYPE_CHECKING:
    from app.models.user import User


class Todo(Model):
    __fillable__ = ["title", "done"]

    title: Mapped[str] = mapped_column(String(255))
    done: Mapped[bool] = mapped_column(Boolean, default=False)
    user_id: Mapped[int] = mapped_column(ForeignKey("users.id"))

    user: Mapped["User"] = belongs_to("User")
```
</CodeFile>

## Let the controller set the owner

The controller will set `user_id` itself, from the signed-in user and never from the form.
Add it to `__fillable__` so `Todo.create()` accepts it. `__fillable__` only limits which keys
your own code can mass-assign, and the form's validated data never includes `user_id`:

```python
    __fillable__ = ["title", "done", "user_id"]
```

The generated migration creates the `todos` table:

<CodeFile name="database/migrations/..._create_todos_table.py">
```python
from alembic import op
import sqlalchemy as sa

revision = "dc57cbb4fa69"
down_revision = "25d246f4b11c"
branch_labels = None
depends_on = None


def upgrade() -> None:
    op.create_table(
        "todos",
        sa.Column("id", sa.BigInteger().with_variant(sa.Integer(), "sqlite"), primary_key=True, autoincrement=True),
        sa.Column("title", sa.String(length=255), nullable=False),
        sa.Column("done", sa.Boolean(), nullable=False),
        sa.Column("user_id", sa.BigInteger().with_variant(sa.Integer(), "sqlite"), nullable=False),
        sa.Column("created_at", sa.DateTime(timezone=True), nullable=True),
        sa.Column("updated_at", sa.DateTime(timezone=True), nullable=True),
        sa.ForeignKeyConstraint(["user_id"], ["users.id"]),
    )


def downgrade() -> None:
    op.drop_table("todos")
```
</CodeFile>

## Give the user side of the relationship

Add the matching `has_many` on `User`, so `user.todos` works later:

<CodeFile name="app/models/user.py">
```python
from aso.database import has_many

class User(MustVerifyEmail, Authenticatable, Model):
    # ...existing columns...

    todos: Mapped[list["Todo"]] = has_many("Todo")
```
</CodeFile>

## Run the migration

```bash
aso migrate
```

```
Migration table migrated successfully.
```

## What you used

- `aso make:model -m -c -r --fields=` — model, migration, and resource controller generation.
  More in [Models and queries](/docs/models) and [Migrations](/docs/migrations).
- `__fillable__` — which attributes `create()` accepts.
- `belongs_to`, `has_many` — relationship declarations. More in [Relationships](/docs/relationships).
- `aso migrate` — applies pending migrations.
