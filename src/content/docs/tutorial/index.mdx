This tutorial builds a small todo app: each signed-in user gets their own list. You'll add a
todo, mark it done, edit its title, and delete it, with validation, flash messages, and
authorization so nobody can touch someone else's todos. Every command and every file in this
guide comes from a real app, built and tested with the steps you're about to follow.

It assumes you've already run `uvx aso new myapp` and have a working app — see
[Installation](/docs/installation) if you haven't.

## What we build

- A `Todo` model and its migration.
- A `TodoController` with `index`, `store`, `update`, and `destroy`.
- One Inertia page, `todos/index.tsx`, with an inline add form and an editable list.
- A `TodoPolicy` so only the owner of a todo can update or delete it.
- Feature tests that cover all of the above.
