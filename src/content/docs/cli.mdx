Run `aso list` in any app to see this same list, generated from the commands actually
registered — including any custom ones you've added with `aso make:command`. Every command
below also takes `--help` for its full option list.

## App info

| Command | Does |
|---|---|
| `about` | Basic info about the app: framework version, environment, drivers in use. |
| `env` | The current framework environment (`local`, `testing`, `production`). |
| `doctor` | Checks Python version, `.env`, the database connection, migrations, and pages. |
| `key:generate` | Writes a fresh `APP_KEY` into `.env` (`--show` prints it without writing). |

## Running the app

| Command | Does |
|---|---|
| `dev` | Python server + Vite + queue worker together (`--port`, `--vite-port`). |
| `serve` | Just the Python server, with uvicorn (`--host`, `--port`). |
| `tinker` | An interactive Python shell with the app already booted. |

## Generators (`make:*`)

| Command | Does | Useful flags |
|---|---|---|
| `make:model` | A model class. | `-m` migration, `-c` controller, `-r` resource, `-f` factory, `-s` seeder, `-a` all of them, `--fields="name:type[:modifier] ..."` |
| `make:controller` | A controller class. | `--resource`, `--api` (resource minus create/edit), `--model=`, `--requests`, `--invokable` |
| `make:request` | A `FormRequest` class. | `--force` |
| `make:middleware` | A middleware class. | `--force` |
| `make:policy` | A policy class. | `--model=` |
| `make:migration` | A migration file (autogenerated from your models, or blank). | `--empty` |
| `make:factory` | A model factory. | `--model=` |
| `make:seeder` | A seeder class. | `--force` |
| `make:job` | A queue job class. | `--force` |
| `make:mail` | A `Mailable` class. | `--force` |
| `make:event` | An event class. | `--force` |
| `make:listener` | An event listener class. | `--event=`, `--queued` |
| `make:command` | A console command class. | `--force` |
| `make:page` | An Inertia page component under `resources/js/pages/`. | `--force` |
| `make:test` | A pytest file under `tests/feature/` (or `tests/unit/`). | `--unit` |

## Database

| Command | Does |
|---|---|
| `migrate` | Runs pending migrations (`--pretend`, `--seed`). |
| `migrate:status` | Which revisions have run. |
| `migrate:rollback` | Undoes the last batch (`--step=N`). |
| `migrate:refresh` | Rolls back everything, then re-runs it. |
| `migrate:reset` | Rolls back every migration, without re-running. |
| `migrate:fresh` | Drops every table and re-runs everything (`--seed`). |
| `db:seed` | Runs a seeder (`--class=`, default `DatabaseSeeder`). |
| `db` | Opens a database CLI session (`psql`/`sqlite3`/...). |
| `db:show` | Info about the current connection. |
| `db:table` | Info about one table's columns. |
| `db:wipe` | Drops every table (no migrations re-run). |

## Routes and frontend

| Command | Does |
|---|---|
| `route:list` | Every registered route: method, URI, name, action, middleware. |
| `routes:generate` | Typed TypeScript route/action helpers (`--with-form`, `--watch`, `--skip-actions`, `--skip-routes`). |

## Queues and scheduling

| Command | Does |
|---|---|
| `queue:work` | Processes jobs as a daemon (`--queue=`, `--concurrency=`). |
| `queue:failed` | Lists failed jobs. |
| `queue:retry` | Retries one or more failed jobs by id, or `--all`. |
| `queue:forget` | Deletes one failed job by id. |
| `queue:flush` | Deletes every failed job. |
| `queue:restart` | Signals workers to finish their current job, then exit. |
| `schedule:list` | Every scheduled task and when it next runs. |
| `schedule:run` | Runs whatever is due right now (what cron calls every minute). |
| `schedule:work` | A long-running process that does the above continuously. |

## Testing

| Command | Does |
|---|---|
| `test` | Runs the suite (`--filter`, `--parallel`, `--coverage`, `--bail`). |

## Housekeeping

| Command | Does |
|---|---|
| `storage:link` | Symlinks `public/storage` → `storage/app/public`. |
| `session:prune` | Deletes expired session rows (database driver). |
| `agents:update` | Rewrites `AGENTS.md`'s generated rules section. |
| `stub:publish` | Copies every generator stub into your app, to customize them. |

## Coming from Laravel

| Laravel | Aso |
|---|---|
| `php artisan` | `aso` (or `uv run aso` outside an activated venv) |
| `php artisan make:model -mcr` | `aso make:model -mcr` |
| `php artisan migrate:fresh --seed` | `aso migrate:fresh --seed` |
| `php artisan route:list` | `aso route:list` |
| `php artisan tinker` | `aso tinker` |
| `php artisan test` | `aso test` |
| `php artisan schedule:work` | `aso schedule:work` |

## Gotchas

- Inside a project, commands run as `uv run aso ...` unless you've activated the virtualenv
  (`source .venv/bin/activate`) — see [Installation](/docs/installation).
- `migrate:fresh`/`db:wipe`/`migrate:reset` are destructive and need `--force` outside
  `local`/`testing` — a safety check, not a missing flag.
- `--fields` on `make:model` only accepts the types `make:model --help` lists; an unknown type
  name is a hard error, not silently ignored.
